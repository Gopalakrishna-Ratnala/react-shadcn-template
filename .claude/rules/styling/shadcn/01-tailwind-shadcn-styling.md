# Styling

## Rules

- Always use Tailwind utility classes for all styling — never write component-scoped CSS
- `src/styles/` is for global files only (resets, CSS variable definitions) — never add component styles there
- Always extract all Tailwind class strings out of `.tsx` files into a co-located `ComponentName.styles.ts` file inside the same component or page folder
- Always use `cva()` (from `class-variance-authority`) in `.styles.ts` files to define component variants
- Always use `cn()` (from `src/lib/utils.ts`) for conditional or composed class strings
- Always include `dark:` counterpart classes alongside every light-mode class — never write light-only styles
- Always style responsively using Tailwind's mobile-first breakpoint prefixes (`sm:`, `md:`, `lg:`, `xl:`)
- Never use the inline `style` attribute — use a Tailwind class or CSS variable instead; inline style props are forbidden even for one-off values
- Never write raw hex, rgb, or rgba values in className strings or style props — use CSS variables defined in `src/styles/globals.css`
- Never use `@apply` anywhere — compose Tailwind classes in `.styles.ts` files instead

## MANDATORY: className Extraction Rule (GAP 1)

**Every `className` value that contains more than one utility class MUST be extracted to the co-located `ComponentName.styles.ts` file as a named `const`.**

The only permitted inline class in JSX is:
- A single-token utility: `className="sr-only"`, `className="contents"`, `className="hidden"`
- A dynamic `cn()` call whose **base classes are imported from `.styles.ts`**, not inlined

```tsx
// WRONG — multi-token className inlined in JSX
<section className="flex flex-col gap-4 p-6 rounded-lg bg-card">

// CORRECT — extracted to styles file, imported in JSX
// ComponentName.styles.ts
export const containerStyles = cn("flex flex-col gap-4 p-6 rounded-lg bg-card");
// ComponentName.tsx
<section className={containerStyles}>

// CORRECT — single token inline (note: never use <span>; use a semantic element or sr-only on a semantic element)
<p className="sr-only">Loading…</p>

// CORRECT — cn() with base imported from styles.ts
<section className={cn(containerStyles, isActive && "ring-2 ring-ring")}>
```

## FORBIDDEN: Template Literals in className (GAP 4)

Template literals in `className` are **forbidden**. Use `cn()` for all conditional or composed class expressions. `cn()` calls must import their base class string from a `.styles.ts` const, not inline the string.

```tsx
// WRONG — template literal
<section className={`flex ${isActive ? 'bg-primary' : ''}`}>

// CORRECT — cn() with imported base
import { containerStyles } from "./Component.styles";
<section className={cn(containerStyles, isActive && "bg-primary")}>
```

## FORBIDDEN: Tailwind Palette Colour Classes (GAP 2)

**NEVER use Tailwind palette classes that reference a fixed colour step.**

Forbidden patterns (any colour name + numeric step):
- `bg-blue-500`, `text-slate-700`, `border-gray-200`, `text-red-400`, `bg-green-600`, etc.

**ALWAYS use the semantic CSS-variable-mapped tokens generated by shadcn/ui:**

| Token | Usage |
| --- | --- |
| `bg-background` / `text-foreground` | Page background and default text |
| `bg-card` / `text-card-foreground` | Card surfaces |
| `bg-popover` / `text-popover-foreground` | Popovers and dropdowns |
| `bg-primary` / `text-primary-foreground` | Primary action colour |
| `bg-secondary` / `text-secondary-foreground` | Secondary action colour |
| `bg-muted` / `text-muted-foreground` | Subdued backgrounds and hint text |
| `bg-accent` / `text-accent-foreground` | Accent highlights |
| `bg-destructive` / `text-destructive-foreground` | Destructive/danger actions |
| `border-border` | Default border |
| `border-input` | Form input border |
| `ring-ring` | Focus ring |

```tsx
// WRONG
<Button className="bg-blue-500 text-white border-gray-200">

// CORRECT
<Button className="bg-primary text-primary-foreground border-border">
```

## Directory Structure

```text
src/
  components/
    ui/                         # shadcn/ui primitives — vendored, never edited
    layout/
      navbar/
        Navbar.tsx
        Navbar.styles.ts        # All Tailwind classes live here — never in .tsx
        ...
    shared/
      authForm/
        AuthForm.tsx            # Component — no raw Tailwind strings
        AuthForm.styles.ts      # Co-located Tailwind class definitions for this component
        types.ts
        AuthForm.stories.tsx    # only when Storybook is enabled
        AuthForm.test.tsx
        index.ts
  pages/
    login/
      LoginPage.tsx
      LoginPage.styles.ts       # Co-located Tailwind class definitions for this page
      types.ts
      LoginPage.test.tsx
      index.ts
  styles/
    globals.css                 # Global resets + CSS variable definitions only
  lib/
    utils.ts                    # cn() helper — import from here, never re-implement
```

## Naming Convention

- Always name style files as `ComponentName.styles.ts`, co-located inside the component or page folder
- Never place component style files in a centralized styles folder — styles live next to their component
- Always export named `const` objects or `cva()` results — never default exports from style files
- Always import styles in the consuming `.tsx` via the named export

## Pattern

```ts
// src/components/shared/authForm/AuthForm.styles.ts
import { cva } from "class-variance-authority";
import { cn } from "@/lib/utils";

export const formContainerStyles = cn(
  "flex flex-col gap-6 rounded-lg p-8",
  "bg-card text-card-foreground",
  "border border-border"
);

export const inputStyles = cva(
  "w-full rounded-md border px-3 py-2 text-sm transition-colors",
  {
    variants: {
      state: {
        default: "border-input bg-background text-foreground",
        error:   "border-destructive bg-destructive/10 text-destructive",
      },
    },
    defaultVariants: { state: "default" },
  }
);

export const submitButtonStyles = cva(
  "w-full rounded-md px-4 py-2 text-sm font-medium transition-colors focus-visible:outline-none disabled:opacity-50",
  {
    variants: {
      variant: {
        primary: "bg-primary text-primary-foreground hover:bg-primary/90",
        ghost:   "bg-transparent text-muted-foreground hover:bg-accent hover:text-accent-foreground",
      },
    },
    defaultVariants: { variant: "primary" },
  }
);
```

```tsx
// src/components/shared/authForm/AuthForm.tsx — no raw Tailwind strings, no <div> or <span>
import { Input } from "@/components/ui/input";
import { Button } from "@/components/ui/button";

import { formContainerStyles, inputStyles, submitButtonStyles } from "./AuthForm.styles";

export function AuthForm() {
  return (
    <section className={formContainerStyles}>
      <Input className={inputStyles({ state: "default" })} />
      <Button className={submitButtonStyles({ variant: "primary" })}>Sign in</Button>
    </section>
  );
}
```
